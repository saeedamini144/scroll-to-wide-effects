# Scroll To Wide Effects

افزونه‌ی ویجت‌های سفارشی برای **المنتور**. در حال حاضر شامل ویجت **Scroll Expand Image** است: تصویری که با اسکرول صفحه از یک کادر کوچک (حتی دایره‌ی کامل) به یک تصویر تمام‌عرض و تمام‌صفحه تبدیل می‌شود و می‌توان روی آن ساب‌عنوان، عنوان، متن و دکمه قرار داد.

- **نسخه:** 1.0.0
- **Text Domain:** `scroll-to-wide-effects`
- **مجوز:** GPL-2.0-or-later

---

## ۱. نیازمندی‌ها

| مورد | حداقل نسخه |
|---|---|
| وردپرس | 6.0 |
| PHP | 7.4 |
| المنتور (Elementor) | 3.20.0 |

اگر المنتور نصب یا فعال نباشد، یا نسخه‌ی PHP/المنتور پایین‌تر از حداقل باشد، افزونه ویجتی ثبت نمی‌کند و فقط یک هشدار در پیشخوان وردپرس نشان می‌دهد (سایت خراب نمی‌شود).

---

## ۲. نصب

1. پوشه‌ی `scroll-to-wide-effects` را کامل داخل `wp-content/plugins/` کپی کنید (یا آن را zip کرده و از «افزونه‌ها ← افزودن ← بارگذاری» نصب کنید).
2. از صفحه‌ی افزونه‌ها، **Scroll To Wide Effects** را فعال کنید.
3. در ادیتور المنتور، در پنل ویجت‌ها دسته‌ی **Scroll To Wide Effects** را پیدا کنید و ویجت **Scroll Expand Image** را روی صفحه بکشید.

---

## ۳. ویجت Scroll Expand Image چطور کار می‌کند؟

ویجت از سه لایه ساخته شده است:

```
.sei            ← بخش اصلی؛ ارتفاعش مسافت اسکرول را تعیین می‌کند (مثلاً 200vh)
 └ .sei__stage  ← صحنه‌ی چسبنده (position: sticky) به ارتفاع یک صفحه‌ی نمایش (100vh)
    └ .sei__frame ← کادر تصویر؛ عرض، ارتفاع و گردی گوشه‌هایش با اسکرول تغییر می‌کند
       ├ img.sei__img
       ├ .sei__shade   (لایه‌ی رنگ روی تصویر)
       └ .sei__layer > .sei__content (ساب‌عنوان، عنوان، متن، دکمه)
```

وقتی کاربر اسکرول می‌کند، صحنه در بالای صفحه می‌چسبد و یک عدد **پیشرفت** (`--sei-p`) از `0` تا `1` توسط جاوااسکریپت محاسبه می‌شود. تمام اندازه‌ها با CSS و بر اساس همین عدد حساب می‌شوند:

```
مقدار فعلی = مقدار شروع + (مقدار پایان − مقدار شروع) × پیشرفت
```

این فرمول برای **عرض**، **ارتفاع** و **گردی گوشه‌ها** اعمال می‌شود. در پایان اسکرول (پیشرفت = ۱) تصویر به حالت «End State» می‌رسد و صحنه از چسبندگی آزاد می‌شود و صفحه ادامه پیدا می‌کند.

## ۴. تنظیمات تب Content

### Image
| گزینه | توضیح |
|---|---|
| Choose Image | انتخاب تصویر از کتابخانه‌ی رسانه (Dynamic Tag پشتیبانی می‌شود، مثلاً تصویر شاخص). |
| Image Size | سایز تصویر؛ شامل Custom. برای `srcset` ریسپانسیو از سایزهای وردپرس استفاده می‌شود. |
| Alt Text | متن جایگزین. اگر خالی باشد از Alt کتابخانه‌ی رسانه استفاده می‌شود. |
| Loading | `Lazy`، `Eager` یا `Eager + High priority`. اگر تصویر بالای صفحه است (LCP) گزینه‌ی آخر را بزنید. |

### Content (محتوای روی تصویر)
| گزینه | توضیح |
|---|---|
| Subtitle | ساب‌عنوان (خالی = نمایش داده نمی‌شود). |
| Title | عنوان؛ با Enter می‌توان آن را چندخطی کرد. |
| Title HTML Tag | تگ عنوان: H1 تا H6، div، span یا p (برای سئو H1/H2 مناسب است). |
| Text | متن توضیحی با ویرایشگر WYSIWYG. |
| Button Text | متن دکمه (خالی = دکمه نمایش داده نمی‌شود). |
| Link | لینک دکمه؛ شامل «باز شدن در تب جدید» و «nofollow». بدون لینک، دکمه به‌صورت `span` رندر می‌شود. |
| Icon / Icon Position | آیکون دکمه و محل آن (قبل یا بعد از متن). |
| Hover Animation | انیمیشن آماده‌ی المنتور هنگام هاور روی دکمه. |

اگر هیچ‌کدام از ساب‌عنوان، عنوان، متن و دکمه پر نباشد، لایه‌ی محتوا و لایه‌ی رنگ روی تصویر اصلاً در خروجی قرار نمی‌گیرند.

### Scroll Animation
| گزینه | توضیح |
|---|---|
| Section Height (Scroll Distance) | ارتفاع کل بخش (۱۰۰ تا ۶۰۰vh). **هرچه بلندتر، انیمیشن کندتر.** حداقل ۱۰۰vh. برای هر دستگاه جداگانه قابل تنظیم است. |
| Easing | `Linear`، `Ease In`، `Ease Out` یا `Ease In Out`؛ منحنی سرعت تغییر. |

## ۵. تنظیمات تب Style

### Layout / Box
- **Horizontal / Vertical Alignment:** جای کادر تصویر داخل صحنه.
- **Background:** پس‌زمینه‌ی صحنه (رنگ یا گرادیانت) که اطراف کادر کوچک دیده می‌شود.

### Image Frame (قلب افکت)
دو حالت تعریف می‌شود و ویجت بین آن‌ها حرکت می‌کند:

**Start State (اسکرول = ۰٪)**
- **Width / Height:** اندازه‌ی شروع (واحدهای vw، %، px برای عرض و vh، %، px برای ارتفاع).
- **Square Start Frame:** کادر شروع را ۱:۱ می‌کند (برابر کوچک‌ترین مقدار عرض و ارتفاع). برای دایره‌ی کامل لازم است.
- **Border Radius:** گردی شروع.

**End State (اسکرول = ۱۰۰٪)**
- **Width / Height:** اندازه‌ی پایان (پیش‌فرض ۱۰۰٪ در ۱۰۰٪).
- **Border Radius:** گردی پایان (پیش‌فرض ۰).

**Box:** رنگ پس‌زمینه، بردر و سایه‌ی کادر تصویر.

### Border Radius چطور کار می‌کند؟
اسلایدر **۰ تا ۱۰۰** است:

- `0` = گوشه‌ی تیز
- `100` = کاملاً گرد (شعاع = نصف ضلع کوتاه‌تر کادر **شروع**)

گردی بر پایه‌ی پیکسل و به‌صورت خطی از مقدار شروع به مقدار پایان می‌رسد، پس حتی وقتی کادر بزرگ می‌شود، گوشه‌ها یکنواخت صاف می‌شوند.

**افکت «دایره ← تصویر تمام‌صفحه»:**
1. Square Start Frame را روشن کنید.
2. Start Width/Height را مثلاً `40vh` بگذارید.
3. Start Border Radius = `100` و End Border Radius = `0`.

> بدون Square Start Frame، گردی ۱۰۰ روی کادر مستطیلی یک بیضی/کپسول می‌سازد، نه دایره.

### Image
Object Fit، Object Position (برای هر دستگاه جدا) و فیلترهای CSS (بلور، روشنایی، کنتراست، اشباع و ...).

### Image Overlay
رنگ یا گرادیانت روی تصویر برای خوانایی متن. پیش‌فرض: مشکی با شفافیت ۳۵٪.

### Content Box
- **Horizontal / Vertical Position:** جای باکس محتوا روی تصویر.
- **Text Alignment:** تراز متن (چپ، وسط، راست).
- **Max Width:** حداکثر عرض باکس محتوا.
- **Distance From Image Edges:** فاصله‌ی باکس از لبه‌های تصویر.
- **Inner Padding، Background، Border، Border Radius، Box Shadow، Backdrop Blur:** استایل خود باکس (مثلاً کارت شیشه‌ای).

### Subtitle / Title / Text
برای هرکدام: رنگ، تایپوگرافی کامل (ریسپانسیو)، Text Shadow، Text Stroke و فاصله‌ی پایین.

### Button
- تایپوگرافی و Text Shadow
- تب **Normal** و **Hover**: رنگ متن، پس‌زمینه (رنگ/گرادیانت)، بردر، سایه
- **Transition Duration:** زمان انتقال هاور
- Padding، Border Radius، فاصله‌ی بالا
- اندازه و فاصله‌ی آیکون

## ۶. عملکرد (Performance)

- فایل‌های CSS و JS فقط **ثبت** می‌شوند و تنها در صفحاتی که ویجت دارند بارگذاری می‌شوند.
- جاوااسکریپت بدون وابستگی (Vanilla JS) و با `defer` در فوتر لود می‌شود.
- محاسبه فقط برای ویجت‌هایی انجام می‌شود که در صفحه‌ی نمایش دیده می‌شوند (`IntersectionObserver`) و با `requestAnimationFrame` به‌روز می‌شود.
- DOM بهینه است و ویجت `.elementor-widget-container` اضافه ندارد.
- در ادیتور المنتور، با هر تغییر تنظیمات، افکت خودکار دوباره راه‌اندازی می‌شود.

## ۷. نکات و رفع مشکل

| مشکل | راه‌حل |
|---|---|
| افکت چسبنده (sticky) کار نمی‌کند | یکی از والدهای ویجت `overflow: hidden/auto/scroll` دارد. این مقدار را روی کانتینرهای والد به `visible` تغییر دهید. |
| انیمیشن خیلی سریع است | Section Height را بیشتر کنید (مثلاً ۳۰۰vh). |
| تصویر کادر را پر نمی‌کند | Object Fit را روی `Cover` بگذارید. |
| متن روی تصویر خوانا نیست | رنگ Image Overlay را تیره‌تر کنید یا برای Content Box پس‌زمینه تعریف کنید. |
| گردی ۱۰۰ بیضی شد | Square Start Frame را روشن کنید. |
| تغییرات بعد از آپدیت فایل‌ها دیده نمی‌شود | کش مرورگر، افزونه‌ی کش و «Regenerate CSS & Data» المنتور را پاک کنید. |
| بعد از تغییر نام، افزونه‌ی قبلی هنوز هست | پوشه‌ی قدیمی `sei-widgets` را غیرفعال و حذف کنید تا با نسخه‌ی جدید تداخل نکند. |

### متغیرهای CSS

| متغیر | معنی |
|---|---|
| `--sei-p` | پیشرفت اسکرول (۰ تا ۱)؛ توسط JS تنظیم می‌شود |
| `--sei-w0` / `--sei-w1` | عرض شروع / پایان |
| `--sei-h0` / `--sei-h1` | ارتفاع شروع / پایان |
| `--sei-r0` / `--sei-r1` | گردی شروع / پایان (۰ تا ۱۰۰) |
| `--sei-section-height` | مسافت اسکرول (ارتفاع بخش) |

## ۹. اضافه کردن ویجت جدید

1. فایل `widgets/class-{name}.php` را بسازید (کلاسی که از `\Elementor\Widget_Base` ارث می‌برد).
2. در `register_widgets()` داخل فایل اصلی، آن را `require_once` کنید و با `$widgets_manager->register( new ... )` ثبت کنید.
3. در صورت نیاز CSS/JS را در `register_styles()` / `register_scripts()` ثبت و در `get_style_depends()` / `get_script_depends()` ویجت معرفی کنید.
